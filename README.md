
# Student Marks Calculator

A simple Python application to calculate student marks, average and grades.

## Features
- Student Roll Number
- Student Name
- Five Subject Marks
- Total Marks Calculation
- Average Calculation
- Grade Calculation
- Pass/Fail Result

## Technologies Used
- Python 3
- Git
- GitHub

## Project Structure

student-marks-calculator/
- main.py
- README.md
- .gitignore
- LICENSE

## How to Run

1. Install Python 3.
2. Clone the repository.
3. Open the project folder in VS Code.
4. Execute:

   python main.py
