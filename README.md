# Student Marks Calculator

A simple Python application to calculate student marks, average and grades.
## Features
- Student Roll Number
- Student Name
- Five Subject Marks
- Total Marks Calculation
- Average Calculation
- Grade Calculation
- Pass/Fail Result

## Technologies Used
- Python 3

## How to Run
1. Install Python.
2. Open the project folder.
3. Run:

   python main.py
